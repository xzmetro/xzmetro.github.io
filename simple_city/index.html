Simple City

A Minecraft Subway Facility Expansion Mod

A very ordinary and simple subway facility expansion mod. It is recommended to add the Minecraft Transit Railway mod for better utilization.

Download

Features

Building Blocks

  • All color wool blocks (Slabs, Stairs, Vertical Slabs)
  • All color concrete blocks (Slabs, Stairs, Vertical Slabs)
  • Ported from Minecraft 26.3

Metro Facilities

  • Station Signs (Low / High)
  • Fire Extinguisher & Cabinet
  • APG Railing (Platform Screen Doors)
  • Train Departure Bell
  • Wuzhou Metro Logo
  • Tactile Paving

Road Facilities

  • Parking Barrier (Left / Middle / Right / Bracket)
  • Road Signs
  • Construction Barriers

Requirements

Dependency Version
Minecraft 1.20.1
Fabric Loader >= 0.14.9
Fabric API *
Java >= 17

Installation

  1. Install Fabric Loader
  2. Place the mod .jar file into your mods/ folder
  3. (Optional) Install MTR Mod for a better experience
